# Snooze Button Roast

`main.ts` (Node 22, stdlib only) writes one line roasting an alarm clock
that rings at 6 AM on a Saturday to `/output/entry.txt`:

> Saturday, six AM, and the clock is the only thing in the house with somewhere to be, which is nowhere.

Deterministic: the same bytes on every run — no clock, no randomness, no
network. See `main.ts` for the line design.
